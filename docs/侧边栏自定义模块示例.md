# 侧边栏自定义模块示例

Mellow 前台右侧栏支持「自定义内容」模块：管理员在后台填一段 HTML，前台原样渲染。
公告、广告位、社交账号、备案信息、快捷入口都可以用这一块解决，不需要改代码。

---

## 一、在哪里配置

**后台 → 系统配置（`/admin/system`）→ 网站表单设置 → 右栏「个性侧边栏」→ 添加模块**

1. 类型下拉里选 **自定义内容**（`html`）
2. 点画布上刚加的模块 → 属性弹窗里填 **标题 / 图标 / 内容**
3. 拖拽或上下箭头调整顺序，点「保存布局」

对应的配置记录是 `config` 表的 `Mellow_functions`（`sidebar.modules[]`），
模块的字段定义见 `Mellow/src/utils/sidebar.js` 的 `SIDEBAR_TYPES`。

### 模块字段

| 字段 | 说明 |
| :--- | :--- |
| 标题 | 卡片头部文字；**留空则不显示标题栏**（变成无边框内容块） |
| 图标 | Bootstrap Icons 类名，如 `bi bi-megaphone`；留空则跟随标题一起隐藏 |
| 内容 | HTML 源码，见下方示例 |
| 可折叠 | 打开后访客可以点标题右侧的箭头收起该模块 |
| 显示 | 关掉后前台不渲染，但配置保留 |

### 渲染细节

- 容器宽度约 **280px**（桌面端右栏），移动端整栏默认隐藏
- `.sidebar-html` 内已内置基础排版：`p` / `ul` / `ol` 有行距，`img` 自适应宽度，`a` 用主题主色
- 可以直接用全局 CSS 变量：`var(--primary)`、`var(--text)`、`var(--text-soft)`、
  `var(--text-muted)`、`var(--bg-card)`、`var(--bg-muted)`、`var(--accent-wash)`、`var(--radius)`

## 二、示例模块

> 下面每段代码都可以整段粘进「内容」输入框。标题与图标在属性面板里单独填，不用写进 HTML。

### 1. 站点公告（左侧强调条）

**标题**：站点公告　**图标**：`bi bi-megaphone`

```html
<div style="padding:10px 12px;border-left:3px solid var(--primary);background:var(--accent-wash);border-radius:6px;font-size:12.5px;line-height:1.75;">
  <p style="margin:0 0 6px;"><strong style="color:var(--primary-deep);">评论区已恢复</strong></p>
  <p style="margin:0 0 6px;">历史评论全部保留，有异常欢迎反馈。</p>
  <a href="/page/about" style="font-size:12px;text-decoration:none;">了解详情 →</a>
</div>
```

### 2. 图文推广位（图片 + 文案 + 按钮）

**标题**：赞助商　**图标**：`bi bi-stars`

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer"
   style="display:block;text-decoration:none;">
  <img src="https://cdn.example.com/banner.jpg" alt="推广"
       style="display:block;width:100%;border-radius:8px;">
  <p style="margin:8px 0 0;font-size:12.5px;line-height:1.6;color:var(--text-soft);">
    云服务器年付 5 折，新用户专享
  </p>
</a>
```

> 图片建议用**站内相对路径**（`/storage/2026/11/xxx.jpg`），外链图可能被防盗链拦掉。

## 三、注意事项

### 1. `<script>` 不会执行

`v-html` 插入的 `<script>` 浏览器不会运行，所以「用 HTML 模块跑一段 JS」是做不到的。
需要动态数据（文章数、在线人数、随机文章）请改用内置模块：
**用户卡片 / 通知 / 随机文章 / 最新评论 / 标签云 / 文章归档 / 站点信息 / 自定义链接**。

### 2. `<style>` 会全局生效

`v-html` 里的 `<style>` 标签作用于**整个页面**，不是只作用于侧栏。
写 `a { color: red }` 会把全站链接染红。

- 推荐：全部用**行内 `style`**（如上例）
- 必须写 `<style>` 时，所有选择器都要带唯一前缀，例如
  `<style>.my-side-card a { ... }</style>` 并把该 class 加在外层 div 上

### 3. 不要用内联事件

`onclick="..."` 这类内联事件**是会执行**的。后台账号一旦被盗，等于给对方留了一个
可以在全站执行的脚本入口。纯展示 + 链接已经够用了。

### 4. 尺寸

侧栏宽约 280px：不要放 `<table>`、`<iframe>`、横向滚动的长代码块，
宽图请加 `style="width:100%"`（`.sidebar-html img` 已有 `max-width:100%` 兜底）。

### 5. 移动端不显示

右栏在窄屏（`< 1024px`）整体隐藏，重要信息不要只放在侧栏，正文里也留一份。

### 6. 保存后刷新前台

侧栏配置跟着站点配置一起下发（前端 store 有缓存），保存后**刷新一次前台**才能看到最新内容。

## 四、排错

| 现象 | 原因 |
| :--- | :--- |
| 前台看不到模块 | 模块「显示」被关掉，或整个右侧栏 `enabled = false` |
| 内容显示成一段纯文本 | HTML 里用了未闭合的标签，浏览器把后面的内容吞进上一个标签 |
| 退出登录后布局错乱 | 内容里用了全局 `<style>`，影响到了其它元素 |
| 图片显示不出来 | 用了外链图被防盗链，或路径写成了 `public/storage/...`（应为 `/storage/...`） |
| 改了没变化 | 前台 store 缓存，刷新页面 |
